# Правила ИСТК

Прочитать [локальную политику](../../docs/1c-rules.md), затем выбрать только строки [общего маршрута](../../docs/1c-standards.md) по намерению. Нормы и дополнительные темы принадлежат указанным там владельцам; повторно уже прочитанный документ не загружать. Для диагностики/навигации использовать matching skill без загрузки руководств разработки.
