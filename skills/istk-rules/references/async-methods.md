# Асинхронные методы 1С

Применять для клиентского кода с `Асинх`, `Ждать`, `Обещание` на платформе
8.3.18 и новее. Версию брать из `.dev.env`. Точную сигнатуру платформенного
метода перед использованием проверять через `1c-syntax`.

## Правила

- Новый асинхронный код писать через методы `*Асинх` и `Ждать`, если версия
  платформы позволяет. `ОписаниеОповещения` оставлять только для совместимости.
- Метод `*Асинх` вызывать из процедуры или функции с ключевым словом `Асинх`.
- Если важны результат или ошибка, обещание обязательно ожидать через `Ждать`.
  Fire-and-forget допустим только при явно зафиксированном контракте ошибок.
- Не рассчитывать, что платформа дождется асинхронного обработчика события формы.
  После первого `Ждать` параметры `Отказ` и `СтандартнаяОбработка` могут быть
  обработаны платформой раньше продолжения метода.
- Для асинхронного диалога из события формы вызывать отдельную `Асинх`-процедуру.
  Запрещающий результат обеспечивать синхронной частью обработчика или отдельным
  сценарием продолжения.
- Обработчик команды формы может быть `Асинх`.
- Сетевые и файловые операции не выполнять внутри транзакции.
