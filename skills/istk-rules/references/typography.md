# Typography Rules

- Use **em-dash** (—) for parenthetical breaks and dialogue; Unicode `U+2014`.
- Use **en-dash** (–) for numeric ranges (1–10); Unicode `U+2013`.
- Use **minus** (−) only for negative numbers; Unicode `U+2212`.
- Use regular hyphen (-) for compound words and hyphenation.
- Use `ё` (yo) correctly in Russian text. Do not replace `ё` with `е` automatically.
- Use proper quotation marks: «кавычки-ёлочки» for Russian.
- Use single quotes ' for nested quotations.
- Use non-breaking spaces (`&nbsp;`) between numbers and units: `10 кг`, `100 ₽`.
- Use non-breaking spaces after single-letter prepositions/conjunctions: `в`, `с`, `к`, `и`, `а`, `но`, `о`, `об`.
