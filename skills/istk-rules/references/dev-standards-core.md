# Локальные метаданные и адаптер стиля

Стиль/API — [методы](../../../docs/1c-methods.md); комментарии задач и синонимы — [локальная политика](../../../docs/1c-rules.md); размещение/префикс — AGENTS. Чужой `.dev.env` и `.claude/rules` не являются gates ИСТК.

## Выбор типа объекта

Справочные данные — справочник; хозяйственная операция — документ; накопление количеств/сумм — регистр накопления; сведения с измерениями — регистр сведений; отчет — отчет/СКД; обработка данных — обработка; фиксированный предметный набор — перечисление. Создание выполнять matching meta skill.

## Локальное именование метаданных

Собственные роли/элементы типовых объектов используют проектный префикс. Внутри нового собственного объекта реквизиты не требуют повторения префикса объекта. Собственные подсистемы добавленных/измененных объектов различать по назначению. Синоним при конфликте дополнить понятным указанием принадлежности; служебный префикс не превращать в пользовательский текст.

Ссылки на код в BSL-комментарии писать нотацией метаданных (`Документ.ЗаказКлиента.МодульОбъекта`); TODO/FIXME содержит номер задачи. При замене типового кода в согласованном допустимом месте сохранять исходный фрагмент комментарием; приоритет расширения задает AGENTS.
