# User Rules — Principles & Profile Management

## Working Principles

1. Работай пошагово; думай перед редактированием кода.
2. Изменения минимальные и точечные — один логический блок за раз.
3. Код должен быть корректным, поддерживаемым и безопасным.
4. Человек в петле: каждое предложение проверяет пользователь.
5. Уточняй детали, если задача неоднозначна.
6. Если в задаче понял не всё — запроси уточнение.

## Profile Loading (kilo)

Профили доступны как prompt-шаблоны в `.kilo/prompts/`. Вызываются через `/имя-шаблона`.

**Доступные шаблоны:** `/code`, `/review`, `/refactor`, `/metadata_management`, `/performance`, `/shell`.

## What to read and when

Перед любой задачей — сначала Read `AGENTS.md` (главный файл инструкций).

Для задач по структуре метаданных — используй prompt-шаблон `/metadata_management`.

Для поиска багов/ошибок — skill `istk-rules`, файл `references/anti-patterns.md`.

Для написания/изменения/ревью кода — skill `istk-rules`; выбрать только затронутые темы по [общему маршруту](../../../docs/1c-standards.md).
