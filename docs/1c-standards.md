# Маршрут стандартов разработки 1С

Индекс, не сборник норм. Перед написанием, изменением или ревью выбрать строки по намерению; читать только выбранные документы. Поиск, диагностика и техническая конвертация сами по себе эти руководства не требуют. Несколько затронутых тем — несколько выбранных строк.

| Намерение / триггер | Единственный владелец |
|---|---|
| Обработчик, жизненный цикл, запись/проведение, подписка, привязка события | [События](1c-events.md) |
| Клиент/сервер, общий модуль, ServerCall, директивы, препроцессор | [Контексты и модули](1c-contexts-and-modules.md) |
| Создание/изменение метода, экспортный API, размещение логики, декомпозиция | [Методы и ответственность](1c-methods.md) |
| Создание/изменение/оптимизация запроса, включая запрос СКД | [Запросы](query-rules.md) |
| Проектирование/изменение семантики СКД: параметры, наборы, ресурсы, варианты, компоновка | [СКД](1c-skd.md) |

Локальная политика ИСТК — [1c-rules.md](1c-rules.md); проверяемые свидетельства — [1c-review-checklist.md](1c-review-checklist.md), для запроса — [query-review.md](query-review.md). Чек-листы проверяют применение руководств, не задают конкурирующие нормы.

Дополнительные владельцы читать только при соответствующей задаче:

- БСП API/повторное использование — [1c-bsp-patterns.md](1c-bsp-patterns.md).
- Именование/создание метаданных — [metadata policy](../skills/istk-rules/references/dev-standards-core.md).
- Компоновка элементов формы — [forms](../skills/istk-rules/references/dev-standards-forms.md).
- `Асинх`/`Ждать` — [async](../skills/istk-rules/references/async-methods.md).
- RLS/права — [access](../skills/istk-rules/references/bsp-access-rights.md).
- Транзакции/блокировки — [locks](../skills/istk-rules/references/locks-and-transactions.md).
- Журналирование — [logging](../skills/istk-rules/references/logging-strategy.md).
- Интеграция — [integrations](../skills/istk-rules/references/integrations.md).

При разработке: выбрать рецепт → проверить метаданные/существующий API через местный RLM/LSP → изменить → применить gates из AGENTS. Незнакомую сигнатуру проверить по справке установленной платформы и контексту вызова. BSL-LS подтверждает диагностируемую часть; руководство объясняет решение. Unica MCP для этого маршрута не требуется.
