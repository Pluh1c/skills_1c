# Поиск и применение API БСП

Перед собственной реализацией типовой операции найти подходящий экспорт реальной версии БСП. Каталог — кандидаты поиска, не доказательство наличия/сигнатуры в любой конфигурации. Provenance SteelMorgan и прежнего API reference — [реестр](external-borrowings.md).

## Рецепт поиска

Через местный RLM/LSP найти модуль, экспорт, документацию и примеры потребителей; получить фактическую сигнатуру. Проверить версию библиотеки, контекст вызова и контракт результата. Если найденное API не подходит, зафиксировать причину собственной реализации. Количество экспортов и универсальные межверсионные сигнатуры не предполагать.

| Операция | Где искать |
|---|---|
| Один/несколько реквизитов по ссылке, пакет ссылок | `ОбщегоНазначения`, семейство `ЗначениеРеквизита*` / `ЗначенияРеквизитов*` |
| Менеджер метаданных по ссылке | `ОбщегоНазначения.МенеджерОбъектаПоСсылке` (возвращает менеджер, не экземпляр объекта) |
| Проверка ссылки/существования | `ОбщегоНазначения`, `ЭтоСсылка`, `СсылкаСуществует` |
| Пользователь/права сеанса | `Пользователи`; проверка доступа/RLS — [профиль прав](../skills/istk-rules/references/bsp-access-rights.md) |
| Пользовательские сообщения | Контекстный API по [локальной политике](1c-rules.md) |
| Шаблоны текста, числа/склонение | `СтроковыеФункцииКлиентСервер` |
| Фон, состояние/отмена длительной работы | `ДлительныеОперации`; контракт работы — [методы](1c-methods.md) |
| Предопределенные элементы, подсистема, ленивое получение модуля | `ОбщегоНазначения`, `ПредопределенныйЭлемент`, `ПодсистемаСуществует`, `ОбщийМодуль` |
| Почта, взаимодействия, адресный классификатор, курсы валют | Соответствующая подключенная подсистема БСП |
| Безопасное хранение | Реальный API безопасного хранилища библиотеки; [интеграции](../skills/istk-rules/references/integrations.md) |
| Регистрация внешнего отчета/обработки | `ДополнительныеОтчетыИОбработки`, matching `epf-bsp-*` |
| Копирование коллекций / групповое проведение | Искать существующий подходящий API; не считать межверсионное имя доказательством контракта |

Положительный рецепт пакетного чтения принадлежит [1c-methods.md](1c-methods.md); правила сообщений — local policy; привилегированный режим/RLS — профилю прав. Здесь только поиск библиотечного API, без конкурирующих стандартов.
