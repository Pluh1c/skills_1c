# Приемка запросов 1С

Нормы и техники — [query-rules.md](query-rules.md), семантика отчета — [1c-skd.md](1c-skd.md). Здесь фиксировать свидетельства применения, не создавать отдельные запреты. Provenance прежнего query review SteelMorgan — [реестр](external-borrowings.md).

## Общие свидетельства

- [ ] Метаданные/типы подтверждены для текущего релиза; ссылки на источник проверки приложены.
- [ ] Ключ, кратность, дубли, NULL и сохранение строк при соединениях проверены на граничных примерах по руководству запросов.
- [ ] Граф пакета (источники → обогащение → результат) использует каждый промежуточный набор; мертвых ВТ нет.
- [ ] Выбранные период/периодичность предоставляют требуемые поля; область чтения соответствует контракту.
- [ ] План/объем/повторное использование обосновывают ВТ и индексы; сравнение результата до/после приложено.
- [ ] Применение локальных соглашений проверено по единственному владельцу query-rules; отклонение имеет решение без потери семантики.
- [ ] Отчет передает фактические значения параметров; итоги, смена варианта, расшифровка и RLS проверены по SKD-рецепту.
- [ ] Ускорение подтверждено сопоставимым runtime-замером либо явно отмечено как статическая гипотеза/deferred.

## Локальная модель доступности ERP

Эта предметная модель не заменяет общие правила запросов. Для `РаспределениеЗапасов` новой версии:

- [ ] Подтверждены `СостояниеЗапаса`, `ХарактеристикаПотребности`, `Количество`; старые `Состояние/ВНаличии/Свободно/Запас` не используются.
- [ ] Агрегаты доступности пересобраны через `СУММА(ВЫБОР ... Количество)` по предметным predicates, не переименованием полей.
- [ ] Мигрированный код не обращается к `Перечисление.РаспределениеЗапасовСостояния.*`.
- [ ] Ненулевое `Количество` не теряется из-за ошибочного условия («ложный ноль»).

## Предметная приемка резервы/СКУД

- [ ] Пакет СКУД соответствует установленному потоку `ВТЛоги → ВТАктуальныйХозорган → ВТИсточники → ВТДляСКД → final SELECT`.
- [ ] Финальное обогащение сохраняет строки требуемыми LEFT JOIN; отбор результата в ГДЕ не обнуляет смысл внешних связей.
- [ ] Себестоимость с НДС/без НДС разделена и явно подписана.
- [ ] Период, подразделение, организация передаются согласно контракту отчета.

Статические gates / deferred runtime — [verification-plan.xml](verification-plan.xml); они не становятся доказательством правильного результата автоматически.
