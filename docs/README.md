# Документация архива

Правила и руководства, используемые скиллами. Точка входа — скилл `istk-rules`
(маршрутизатор: `SKILL.md` → `1c-rules.md` + `1c-standards.md`, дальше — только
затронутые темы; `references/` читаются лениво).

## Правила разработки 1С (переносимы между контурами)

| Документ | Назначение |
|---|---|
| `1c-rules.md` | Локальная политика BSL: границы, стиль, обработка ошибок |
| `1c-standards.md` | Общий маршрут стандартов по намерению |
| `query-rules.md` | Создание и оптимизация запросов 1С |
| `query-review.md` | Приёмка запросов |
| `1c-skd.md` | Проектирование СКД и передача параметров |
| `skd-guide.md` | Схема компоновки данных: полное руководство |
| `1c-events.md` | События объектов и управляемых форм |
| `1c-methods.md` | Методы, ответственность, API |
| `1c-contexts-and-modules.md` | Контексты выполнения и настройки модулей |
| `1c-bsp-patterns.md` | Поиск и применение API БСП |
| `1c-review-checklist.md` | Чек-листы ревью BSL-кода и метаданных |

## Инфраструктура и оркестрация (специфичны для контура ИСТК)

Эти документы описывают инструменты конкретного контура (RLM, bsl-ls, Kilo/Codex,
OpenSpec) и в общем случае неприменимы к развёртыванию OpenCode «как есть»; при
переносе требуют адаптации.

| Документ | Назначение |
|---|---|
| `mcp.md` | MCP-инфраструктура контура (RLM, bsl-ls, 1c-syntax) |
| `capability-map.md` | Карта capability → инструмент |
| `agent-tool-contracts.md` | Границы доказательности инструментов |
| `agent-ops.md` | Tiering, декомпозиция, durable state |
| `plan-controller.md` | Plan Controller (DevRails) → OpenSpec |
| `rlm-workflow.md` | Работа через RLM |
| `rlm-subsystem-analysis.md` | Полный анализ состава подсистемы через RLM |
